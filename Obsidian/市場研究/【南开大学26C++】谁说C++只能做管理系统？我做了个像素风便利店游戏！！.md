南开计算机小登的 C++ 大作业展示来了！  
  
没有做传统的管理系统，而是用 C++ + Qt6 做了一个 2D 像素风海边便利店模拟经营游戏：Tideshore / 潮汐小镇。  
  
玩家可以在每天营业前进货、调价，营业后查看结算，再升级店铺、进入下一天，形成一个完整的经营闭环。项目里也做了存档、UI 音效、鼠标点击特效和 Release 打包。  
  
源码和可运行 Release 版本都在 GitHub：  
https://github.com/Pperegrine/Tideshore  
  
感谢支持！！
