AI 写代码越来越快，我却发现自己 review 的速度开始成为开发的瓶颈。直接接受改动又不踏实，怎么办？  
  
这期拿《技能连珠》的真实开发过程，分享我怎样用 GitHub Projects 做好前期规划、中期跟进和后期验收：建立版本里程碑，明确目标与关键结果，把任务整理成 Issue；完善设计后交给 AI 开发，通过 PR 检查改动，再结合试玩和测试决定是否合并。  
  
也会讲到 Table、Board、Roadmap 三种视图，以及优先级、状态和完成记录怎样帮助个人开发。这套流程同样适合小团队协作。  
  
你与 AI 开发时，最容易卡在设计、review 还是试玩验收？欢迎在评论区交流。
