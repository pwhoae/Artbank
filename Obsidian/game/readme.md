**拆解中間幀（Breakdown Frames）的重要性**：

### **大師與資源推薦名冊**

| 推薦大師 / 資源 | 核心學習價值與特長 |
| :---- | :---- |
| **Y N B M** | 極度高效的動畫師，經常在直播中示範如何以最聰明、最快的方式使用 Clip Studio Paint（包括巨集功能、圖層堆疊與動畫資料夾管理）。 |
| **Gozu (Dosu)** | 作者推崇為「地表最強的 Layout（佈局）動畫師」。 |
| **Yu Takanaka Mura (中村豊)** | **「Back Frames（方塊/碎片特效）」的發明者**，曾為 Riot 製作人氣音樂錄影帶，其作畫充滿了極致的弧度運動。 |
| **Taco** | **形體學與人體結構簡化的大師**。如果想要大幅提升作畫造型的視覺吸引力（Appeal），他的拆解作品是必讀聖經。 |
| **Flying Panda** | 製作了全網最棒、最深度的\*\*「波動原理（Wave Principle）」\*\*教學影片（探討力量如何穿透主體並使其形變延遲跟隨）。 |
| **Toniko Panto** | 想打好最紮實的動畫十二法則基本功，他的基礎教學是必看首選。 |
