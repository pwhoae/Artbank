Learning to develop games can be an overwhelming process. There are so many different options out there... to many options out there. If you are an absolute beginner this video is meant to guide you through the process, first with choosing a game engine, then initial applications to focus on if you want to learn pixel art, music creation, 3D art and then further game engine recommendations once you've got the basics. All of the mentioned applications are free (except one... sorta) and links can be found in the linked article down below.
