### 动画技巧(靈活感>頭髮飄動+呼吸+眨眼+輕微身體搖擺+衣服飄動)  **加速度与减速度,速度与间距** 改變 動畫 流暢

1. 主观轨迹:可以打破现实法则，使用主观夸张的运动轨迹。
2. 物化转换:将角色与其它物体的特质互换，改变其形态、幅度、速度或时间，甚至突破常规形体（“破形”）。[将吃草的牛结合“收割机”的形态与嘴部运作方式，并配上收割机音效。]  
3. 拟人化:将角色的行为赋予人类的共通行为特征[把牛吃草的行为提炼为“肥宅躺床上伸手抓薯片吃/蹬腿”的拟人动作。]  
4. 快慢节奏[让“低头吃”快而迅速，让“咀嚼”相对静止变慢]  
5. 材质替换:在角色运动过程中，将局部部位的材质属性替换（如替换成有弹性的橡胶等），使其在受力时产生弹性拉伸或形变
