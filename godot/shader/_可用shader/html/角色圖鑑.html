如何在 Godot 4 中安裝圖鑑系統

只要遵照以下 4 個步驟，即可在您的 Godot 專案中完美復刻此圖鑑系統。

💡 系統設計理念：資料與 UI 分離

本系統採用數據驅動（Data-Driven）架構。角色設定存放於 JSON 或 Godot 專屬自定義 Resource。UI 僅負責讀取與渲染，此舉有利於後續更新、拓展大量角色或從伺服器端同步數據。

1 創建角色數據結構 (Custom Resource)

在專案中新建一個名叫 CharacterData.gd 的腳本，該類繼承自 Resource，用來在編輯器中靈活配置各個角色的基礎數值。

  • 您可以在 Godot 編輯器內右鍵 -> 新建 Resource -> 搜尋您的 CharacterData 資源，手動在屬性面板編輯。
  • 或者，也可以將其做為動態資料結構，直接讀取本工具生成的 character_data.json。

2 設置全域單例管理者 (Autoload Singleton)

創建 EncyclopediaManager.gd，將其在專案設定的 **Autoload (自動載入)** 中註冊為全域單例。它負責：

  • 初始化載入所有角色的 Resource / JSON 設定檔案。
  • 維持目前玩家的「解鎖狀態字典」（儲存於 user://unlocked_characters.json）。
  • 提供全局方法例如 unlock_character(id) 以及對應的訊號傳遞，讓其餘 UI 或系統得以綁定與刷新。

3 建置 UI 節點層級 (Scene Structure)

在您的圖鑑介面場景中，推薦以下列 Node 階層配置：

└─ EncyclopediaUI (Control)
   ├── Background (TextureRect - 漸層暗底)
   ├── HBoxContainer (主要左右分割佈局)
   │   ├── LeftPanel (PanelContainer - 篩選網格區)
   │   │   └── VBoxContainer
   │   │       ├── SearchBar (LineEdit)
   │   │       ├── FilterOptions (HBoxContainer with Buttons/OptionButtons)
   │   │       └── ScrollContainer
   │   │           └── CharacterGrid (GridContainer)
   │   └── RightDetailPanel (PanelContainer - 點選角色卡展現詳情)
   │       └── VBoxContainer
   │           ├── CharName (Label)
   │           ├── CharArt (TextureRect / Shader)
   │           ├── StatsGrid (GridContainer with HP/ATK ProgressBars)
   │           └── BioText (RichTextLabel)
   └─ CardItem_Template (自製角色卡預製件，包含 Button/TextureRect/LockIcon)

4 編寫與綁定 UI 控制邏輯

將 EncyclopediaUI.gd 掛載至最上層控制節點。它會在啟動時：

  • 調用全域單例，獲取目前角色列表、動態生成對應的 Character Card 場景並塞入 GridContainer。
  • 點選卡牌時，將資料傳遞給右側資訊欄。
  • 未解鎖角色會被套用**黑白灰階 Shader**，並且覆蓋一個上鎖標誌。
