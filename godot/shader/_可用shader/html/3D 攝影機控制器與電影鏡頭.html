实现核心: CameraController.gd
GDScript

以下代码实现了通过单个 Camera3D 节点，在游戏里用平滑的线性插值（Lerp）和球形平滑过渡各种预设。只需在场景中创建不同的 Marker3D 节点，摄像机将会在它们之间优雅地滑行和调整视角。 

# ==============================================================================
#                      3D 游戏/电影多视角摄像机控制器 (Godot 4.x)
# ==============================================================================
extends Camera3D

# 定义视角模式枚举
enum CamMode {
	FIRST_PERSON,     # 第一人称
	SECOND_PERSON,    # 第二人称 (过肩/对话)
	THIRD_PERSON,     # 第三人称 (动作冒险)
	CLOSE_UP,         # 演员特写 (Close-Up)
	EXTREME_CLOSE_UP, # 演员大特写 (Extreme Close-Up)
	LOW_ANGLE,        # 仰拍
	HIGH_ANGLE,       # 俯拍
	DUTCH_ANGLE,      # 荷兰角斜拍
	BIRDS_EYE         # 鸟瞰
}

@export_group("摄像机定位锚点 (Marker3D)")
# 挂载在玩家(或剧场中心)子节点下的定位锚点
@export var first_person_marker: Marker3D
@export var second_person_marker: Marker3D
@export var third_person_marker: Marker3D
@export var close_up_marker: Marker3D
@export var extreme_close_up_marker: Marker3D
@export var low_angle_marker: Marker3D
@export var high_angle_marker: Marker3D
@export var dutch_angle_marker: Marker3D
@export var birds_eye_marker: Marker3D

@export_group("平滑插值参数")
@export var transition_speed: float = 5.0 # 平滑插值速度 (值越大越迅速)
@export var rotation_speed: float = 6.0   # 旋转平滑速度
@export var fov_speed: float = 4.0        # 视场角缩放插值速度

# 默认设置当前视角
@export var current_mode: CamMode = CamMode.THIRD_PERSON

# 运行时用于控制各模式的特定 FOV 参数
var mode_fovs: Dictionary = {
	CamMode.FIRST_PERSON: 85.0,
	CamMode.SECOND_PERSON: 55.0,     # OTS 焦段偏窄，有纵深压缩感
	CamMode.THIRD_PERSON: 70.0,
	CamMode.CLOSE_UP: 35.0,          # 电影特写建议使用长焦 (低FOV)，减少面部畸变
	CamMode.EXTREME_CLOSE_UP: 20.0,  # 极其狭窄的长焦
	CamMode.LOW_ANGLE: 65.0,
	CamMode.HIGH_ANGLE: 75.0,
	CamMode.DUTCH_ANGLE: 65.0,
	CamMode.BIRDS_EYE: 60.0
}

# 当前正在插值的目标定位节点
var target_marker: Marker3D
# 电影导演镜头可能会有特殊的 Z 轴（滚转角 Roll），用于类似荷兰角的旋转
var target_roll: float = 0.0

func _ready() -> void:
	# 检查初始化锚点
	_update_target_marker()
	if target_marker:
		global_transform = target_marker.global_transform
		fov = mode_fovs[current_mode]

func _process(delta: float) -> void:
	_update_target_marker()
	if not target_marker:
		return

	# 1. 位置插值 (Lerp Location)
	global_position = global_position.lerp(target_marker.global_position, transition_speed * delta)

	# 2. 旋转插值 (Slerp Rotation)
	# 使用四元数进行平滑旋转，避免万向节锁
	var current_quat = global_transform.basis.get_rotation_quaternion()
	var target_quat = target_marker.global_transform.basis.get_rotation_quaternion()
	
	# 如果是荷兰角，给目标四元数人为叠加 Z 轴倾斜
	if current_mode == CamMode.DUTCH_ANGLE:
		# 倾斜大约 -15 度
		var roll_offset = Quaternion(Vector3.FORWARD, deg_to_rad(-15.0))
		target_quat = target_quat * roll_offset
		
	var final_quat = current_quat.slerp(target_quat, rotation_speed * delta)
	global_transform.basis = Basis(final_quat)

	# 3. 视场角插值 (Lerp FOV) - 电影长焦的关键
	var target_fov = mode_fovs.get(current_mode, 70.0)
	fov = lerp(fov, target_fov, fov_speed * delta)

# 核心：根据枚举切换目标锚点
func switch_camera_mode(new_mode: CamMode) -> void:
	current_mode = new_mode
	_update_target_marker()

# 获取当前枚举对应的 Marker3D
func _update_target_marker() -> void:
	match current_mode:
		CamMode.FIRST_PERSON:
			target_marker = first_person_marker
		CamMode.SECOND_PERSON:
			target_marker = second_person_marker
		CamMode.THIRD_PERSON:
			target_marker = third_person_marker
		CamMode.CLOSE_UP:
			target_marker = close_up_marker
		CamMode.EXTREME_CLOSE_UP:
			target_marker = extreme_close_up_marker
		CamMode.LOW_ANGLE:
			target_marker = low_angle_marker
		CamMode.HIGH_ANGLE:
			target_marker = high_angle_marker
		CamMode.DUTCH_ANGLE:
			target_marker = dutch_angle_marker
		CamMode.BIRDS_EYE:
			target_marker = birds_eye_marker

前端 UI 按键触发关联脚本

将以下逻辑绑定在场景内的 `Button` 上，通过简单的信号触发模式切换：

# Button UI 绑定的控制脚本示例
extends Control

@export var camera_controller: Camera3D # 拖入挂载了上述脚本的 Camera3D

func _on_first_person_btn_pressed():
	camera_controller.switch_camera_mode(camera_controller.CamMode.FIRST_PERSON)

func _on_close_up_btn_pressed():
	camera_controller.switch_camera_mode(camera_controller.CamMode.CLOSE_UP)

上帝说：“让场景井井有条。”

在 3D 游戏开发中，不应该直接写死摄像机的绝对数值。最优秀、最容易维护的做法是： “锚点定位法”。在角色的特定物理坐标轴下，建立不同的空节点（Marker3D），用于充当摄像机的目标终点。

Godot 场景树节点树层级关系 (Scene Tree)
📦 World3D (主场景根节点)
├── ☀️ DirectionalLight3D (主光源)
├── 🧱 CSGBox3D (地面环境障碍物)
└── 👤 Player (你的物理玩家 - CharacterBody3D)
├── CollisionShape3D (物理碰撞体)
├── MeshInstance3D (玩家外观模型/演员)
└── ⚙️ CameraAnchors (用于管理相机各机位的父容器 Node3D)
├── 📍 FirstPersonMarker (位置置于头部前侧, rotation.y = 0)
├── 📍 SecondPersonMarker (位置置于右肩后上方, 略微朝向玩家前方)
├── 📍 ThirdPersonMarker (经典后撤机位, 距离2-4米, 稍微斜俯)
├── 📍 CloseUpMarker (置于正前方 1.2米，高度对准面部)
├── 📍 LowAngleMarker (置于脚底下方向上仰望 30度)
└── 📍 BirdsEyeMarker (高空 8米 垂直向下俯视)
└── 🎥 Camera3D (挂载 CameraController.gd 脚本，并在属性面板拖入映射上述所有📍锚点)

专家开发建议

由于玩家节点在转动时会带着子节点（CameraAnchors）一起转动，摄像机会自动跟随旋转，所以摄像机本身不需要处理过于复杂的绕转物理代码，完全交由 Godot 内置的物理父子层级同步完成。

CU 特写镜头 (Close-Up)

游戏代表：《底特律：化身为人》对话选择、各种高沉浸式剧情演出的对焦。
技术要点：必须调低视场角（FOV 降低至 35°左右），相当于相机镜头拉远但焦距变长。这能极大消除由于近景导致的“透视大鼻子畸变”，让面部轮廓显得平整专业。

Dutch 荷兰角斜拍 (Dutch Angle)

游戏代表：《生化危机》恐怖逃生阶段、BOSS 出场特写、角色丧失神智。
技术要点：人为增加 Z 轴（Roll 翻滚度）15°到 25° 的偏转。该镜头故意破坏画面的水平平衡感，向观众传递紧张、不安、混乱、甚至精神错乱的情感暗示。

Low 低角度仰拍 (Low Angle)

游戏代表：《只狼：影逝二度》义父或弦一郎战前亮相、巨型怪物登场、机甲庞大体态展示。
技术要点：相机高度大幅降低（置于胸腔、膝盖甚至脚踝以下），朝向上方仰视。这会令拍摄主体高大、压抑、具有不可一世的权威性与力量感。

OTS 过肩双人对话 (Over-the-Shoulder)

游戏代表：《巫师3》、《质量效应》等经典 RPG 对话。
技术要点：利用前景（说话者后肩部轮廓，通常失焦模糊）作为框架，对焦框住远处说话的角色。它能够将玩家拉入对话当事人的真实空间，比干瘪的上帝视角对话更有主观参与度。
