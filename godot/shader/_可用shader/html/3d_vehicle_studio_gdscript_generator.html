VehicleBody3D Configuration Tips

  • Mass: Set VehicleBody3D.mass between 1000.0 and 1800.0 kg.
  • Center of Mass: Move the center of mass lower (Y: -0.3 to -0.5) to prevent easy flipping when drifting or turning sharp corners.
  • Wheel Placement: Assign each VehicleWheel3D as a direct child of VehicleBody3D. Ensure wheel radii match your visual wheel mesh.
  • Wheel Drive: Enable Use Steering on front wheels, and Use Engine on rear wheels (RWD) or all 4 wheels (4WD).

Project Input Map Actions

Ensure your Godot Project Settings → Input Map has the following keybindings configured:

ui_up : W / Up Arrow
ui_down : S / Down Arrow
ui_left : A / Left Arrow
ui_right : D / Right Arrow
ui_select : Spacebar (Handbrake)
reset_vehicle : R key
