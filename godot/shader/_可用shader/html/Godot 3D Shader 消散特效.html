Godot 引擎配置与使用指南

1 材质节点设置

在 Godot 场景中，选择您的 3D 节点 (例如 MeshInstance3D)，在属性面板中新建或分配一个 ShaderMaterial，然后将上方复制的着色器代码粘贴进新着色器中。

2 关键属性及剔除设置

为了使模型内部在消散后也能正确看到，代码内默认开启了 cull_disabled (不剔除背面)。建议在 Shader Parameters 中指定一张 Albedo Tex 纹理贴图。

3 代码动画集成

使用 GDScript 或 AnimationPlayer 对着色器变量 dissolve_amount 在 0.0 至 1.0 之间进行插值，即可在游戏运行时完美实现物体消融的过场特效。
