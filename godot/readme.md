# **🎮 Godot Resource Bank & Development Notes**

歡迎來到 **Artbank \- Godot 專案資源庫**！本倉庫整理了各種 Godot 4 的遊戲機制原型、Shader 視覺效果、工具套件、音效 UI 範例以及個人開發筆記。

## **🛠️ 推薦與整合 Addons**

專案中整合或推薦使用的核心插件（Plugins）：

* 🪄 **TweenFX** \- 強大的動畫與補間動畫特效擴充  
* 💬 **Dialogue** \- 對話系統與文本流程管理  
* 🧹 **Import Cleaner** \- 自動化整理與清理未使用的匯入資產  
* 🎬 **Tween Composer** \- 視覺化 Tween 編輯器，加速 UI 與動作調校
