## 🚇 游戏 Demo 策划案：都市极速 (Urban Sprint)

### 1. 核心概念

* **游戏类型**：3D 无尽跑酷 (Infinite Runner)
* **视角**：第三人称背后视角 (追逐视角)
* **核心循环**：奔跑 -> 闪避障碍 -> 收集货币 -> 获取道具 -> 挑战高分
* **特色机制**：增加一个“动态天气系统”，不同天气会影响地面摩擦力和视野，增加游戏难度。

### 2. 关卡设计

* **环境**：现代赛博朋克风格的地铁站，包含轨道、维修平台、列车顶端。
* **操作**：
* **左/右滑动**：切换跑道 (3条跑道)。
* **上滑**：跳跃。
* **下滑**：翻滚。


* **主要道具**：
* **飞行背包**：进入空中自动收集金币。
* **磁铁**：自动吸收周围金币。
* **加速鞋**：短时间内提升移动速度。

# 🧠 四、玩家控制（player.gd）

👉 三条跑道 + 跳跃 + 下滑

```gdscript id="ijj5dt"
extends CharacterBody2D

const LANES_Y = [200, 300, 400]  # 三条跑道（上下）
var current_lane = 1

var gravity = 1200
var jump_force = -500
var speed = 200

func _physics_process(delta):
    velocity.x = speed
    
    if not is_on_floor():
        velocity.y += gravity * delta
    
    move_and_slide()

    # 平滑移动到目标跑道
    var target_y = LANES_Y[current_lane]
    position.y = lerp(position.y, target_y, 0.2)

func _input(event):
    if event.is_action_pressed("ui_up"):
        current_lane = max(0, current_lane - 1)
    elif event.is_action_pressed("ui_down"):
        current_lane = min(2, current_lane + 1)
    elif event.is_action_pressed("ui_accept"):
        if is_on_floor():
            velocity.y = jump_force
```

# 🔁 八、生成障碍（main.gd）

```gdscript id="ulth7l"
extends Node2D

@onready var player = $Player
var obstacle_scene = preload("res://scenes/Obstacle.tscn")

const LANES_Y = [200, 300, 400]

func _ready():
    spawn_loop()

func spawn_loop():
    while true:
        await get_tree().create_timer(1.2).timeout
        spawn_obstacle()

func spawn_obstacle():
    var obs = obstacle_scene.instantiate()
    
    var lane = randi() % 3
    obs.position = Vector2(800, LANES_Y[lane])
    
    add_child(obs)
```

# 🧠 三、玩家控制（player.gd）

实现三条跑道 + 跳跃 + 下滑

```gdscript
extends CharacterBody3D

const LANES = [-2, 0, 2]
var current_lane = 1
var speed = 10
var jump_velocity = 8
var gravity = 20

func _physics_process(delta):
    velocity.z = -speed
    
    if not is_on_floor():
        velocity.y -= gravity * delta
    
    move_and_slide()

func _input(event):
    if event.is_action_pressed("ui_left"):
        current_lane = max(0, current_lane - 1)
    elif event.is_action_pressed("ui_right"):
        current_lane = min(2, current_lane + 1)
    elif event.is_action_pressed("ui_accept"):
        if is_on_floor():
            velocity.y = jump_velocity
    
    # 平滑移动到目标跑道
    var target_x = LANES[current_lane]
    position.x = lerp(position.x, target_x, 0.2)
```
