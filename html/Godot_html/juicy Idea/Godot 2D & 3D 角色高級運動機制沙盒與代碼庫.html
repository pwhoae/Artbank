``` ### 系統架構與 9 大動作機制設計總覽 1. **基礎運動與滑鏟 (Basic Movement & Slide)** - **核心原理**：基於 Godot 4 的 `CharacterBody3D` / `CharacterBody2D`。平滑處理加速度與減速度，並在速度高於閾值時切換至 `SLIDE` 狀態。 - **碰撞體處理**：動態調降 `CollisionShape3D` 的 `height` (例如從 2.0m 縮至 1.0m)，並施加上滑動量 (Impulse) 與衰減阻力。 2. **翻越系統 (Vaulting System)** - **雙射線偵測**：上方頭部射線 (`RayHead`) 與下方腿部射線 (`RayKnee`)。 - **觸發條件**：當膝蓋射線撞擊低矮障礙物但頭部射線未碰撞時，代表前方為低掩體。利用 `Tween` 將玩家位置補間移至障礙物頂端。 3. **掩體系統 (Cover System)** - **牆面吸附**：發射 RayCast 取得障礙物法線 (`get_collision_normal()`)。 - **向量切線**：利用 `normal.cross(Vector3.UP)` 計算沿牆切線，鎖定玩家移動軸向。 4. **攀爬系統 (Climbing System)** - **區域接合**：使用 `Area3D` 偵測梯子或攀爬網。進入區域後將重力感應係數降為 `0`，將前後/上下輸入直接映射至垂直 $Y$ 軸速度。 5. **爬牆與懸崖抓握 (Wall Climbing / Ledge Grab)** - **懸崖檢測**：當玩家處於空中靠近牆面時，牆面射線命中但頂部懸崖射線穿透，觸發抓持 (Hang) 狀態。按下跳躍鍵觸發翻上動畫。 6. **平衡與走獨木橋 (Balance / Narrow Walk)** - **狹窄區域檢測**：下方射線檢測到 `NarrowBeam` 標籤，啟用速度上限並根據身體離心率計算 `rotation_degrees.z` 傾斜角度。 7. **蹬牆跳與滑牆 (Wall Jump & Wall Slide)** - **滑牆**：下落時 `is_on_wall()` 成立，限制最快下落速度 $V_y$。 - **蹬牆**：觸發跳躍時取得 `get_wall_normal()`，給予法線方向反彈力與垂直向上彈力。 8. **閃避與通用動作 (Evasion / Dash)** - **爆發位移**：提供短期高倍率速度補貼，配合 Timer 鎖定狀態並啟用無敵時間 (i-Frames)。 9. **預測運動系統 (Motion Prediction)** - **物理拋物線繪製**：利用 $P(t) = P_0 + V_0 t + \frac{1}{2}g t^2$ 生成預測點陣列，透過 `ImmediateMesh` 或 `Line2D` 實時繪製軌跡。
