# 挂载到 Area3D / Node3D / MeshInstance3D 上的 3D 悬停控制脚本
3D 描边核心原理：反转外壳法 (Inverted Hull / Next Pass) Godot 3D 中实现卡通高品质描边最主流的方法是给网格材质添加 Next Pass 材质，通过在顶点着色器中沿法线（Normal）向外挤出，并反转剔除面（cull_front）包裹原模型。
  1. 在 Inspector 中配置 Next Pass： 选择你的 3D 模型 MeshInstance3D → 展开 Material → 选择主材质 → 展开 Next Pass 属性 → 新建一个 ShaderMaterial。
  2. 加载描边 Shader： 将本工具生成的 3d_outline.gdshader 填入该 Next Pass 的 Shader 栏。
  3. 3D 鼠标悬停检测配置 (Area3D)： 为 3D 模型节点添加 Area3D 节点和 CollisionShape3D 碰撞体。将 Area3D 的 mouse_entered 与 mouse_exited 信号连接到脚本。

Godot 3D 节点结构参考 (Node Hierarchy)：

📁 CharacterItem3D (Node3D or Area3D)
├── 🧊 MeshInstance3D (Material -> Next Pass -> Outline Shader)
└── 🔲 CollisionShape3D (用于 Area3D 3D 鼠标拾取检测)
