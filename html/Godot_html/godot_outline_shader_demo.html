关键提醒：解决 Sprite 描边边缘被裁剪 (Clipping) 边缘丢失问题 在 2D Shader 中，描边如果超出纹理的原始尺寸，外侧描边会被切平。Godot 中常见解决方案：
  1. 增加纹理外边距 (Padding/Margin)： 在导出 PNG 图像资源时，在图片四周预留 10px~20px 的透明像素空间。
  2. 使用 TextureRect / NinePatchRect： 若使用 TextureRect 节点，将 Expand Mode 设为 Ignore Size 或 Keep Aspect，稍微调大 Rect 尺寸即可。
  3. 节点信号绑订说明： 如果节点是 Area2D，连接 mouse_entered 和 mouse_exited 信号到脚本；如果节点继承自 Control，原生自带悬停信号。
