# 《羈絆棋戰》Demo 策劃書 + AI 美術素材 Prompt

Game Design Document · Prototype Plan · AI Art Asset Guide

我會將你的構想整理成一款 「3×3 井字棋 × 角色貼紙收集 × 戰棋佔位 × 回合制戰鬥」 的小型遊戲 Demo，暫定名稱為《羈絆棋戰》（Bond Tactics）。

核心特色是：先在棋盤上佔位，再透過相鄰戰鬥、角色技能與羈絆效果爭奪勝利。佔領位置後，角色不能任意逃跑，必須承擔自己的戰術選擇。

美術方向採用日系 Q 版角色、收藏貼紙、桌遊棋盤與明亮的動漫遊戲 UI，適合先製作一個可玩的 2D Demo，之後再擴充角色、技能與關卡。

## 1. 遊戲核心設計

3×3 井字棋棋盤

共 9 個位置，以三子連線為基礎勝利條件。

5×2 角色貼紙陣容

10 張角色貼紙，雙方各 5 名。每個角色擁有定位、技能及羈絆。

佔位即交戰

角色佔領棋格後進入交戰狀態，不能任意移動或逃離，必須依規則戰鬥。

每回合一步行動

下棋、攻擊或施放技能；部分技能可以突破一般行動限制。

### 遊戲定位

- 類型：2D 回合制策略、輕量戰棋、角色收集。
- 單局時間：3–8 分鐘。
- 玩家人數：1 人對 AI，後續可加入雙人本地對戰。
- Demo 範圍：一張棋盤、10 名角色、數種技能、一個 AI 對手。
- 建議製作方式：先以 Godot 2D 或 Unity 2D 製作，採用資料驅動角色與技能系統。

### 2.2 每回合的行動

建議採用「一回合一個主要行動」的規則，讓玩家容易理解，也能保留技能的策略性。

| 行動    | 效果             | 限制           |
| ----- | -------------- | ------------ |
| 下棋／佔位 | 從備戰區派出角色到空格    | 每次佔領一格       |
| 攻擊    | 攻擊範圍內的敵人       | 消耗本回合行動      |
| 施放技能  | 執行角色的特殊效果      | 依技能規則消耗行動或能量 |
| 羈絆召喚  | 召喚符合條件的角色或建立標記 | 需要觸發條件       |

佔位後的限制：

1. 角色進入棋格後，不能主動離開該格。
2. 角色可以攻擊相鄰敵人，或使用技能攻擊其他格子的敵人。
3. 角色被擊敗後移出棋盤，該格重新成為空格。
4. 不能直接交換己方角色的位置，也不能透過一般移動逃避戰鬥。
5. 如果技能會改變位置，必須明確標記為特殊規則；第一版 Demo 建議先不加入位移技能。

這樣能讓每一次佔位都具有風險：玩家不只是在連線，也是在決定哪些角色要承受敵人的壓力。

### 2.4 攻擊與戰鬥

建議使用容易平衡的簡化數值：

| 屬性       | 建議範圍  | 用途        |
| -------- | ----- | --------- |
| HP 生命    | 2–5   | 歸零後角色退場   |
| ATK 攻擊   | 1–2   | 每次命中造成的傷害 |
| Range 射程 | 1–2 格 | 決定可攻擊的位置  |
| Skill 技能 | 1 個   | 形成角色差異    |
| Bond 羈絆  | 0–3 層 | 觸發強化效果    |

距離計算建議使用曼哈頓距離：

\\[ d=|x_1-x_2|+|y_1-y_2| \\]

例如，位於棋盤中心的角色與四個正交方向的棋格距離為 1，與四個角落的距離為 2。

- 近戰角色：只能攻擊距離 1 的敵人。
- 遠程角色：可以攻擊距離 1–2 的敵人。
- 範圍攻擊：對指定棋格及其鄰格造成傷害。
- 攻擊被擊敗的角色：不允許。
- 攻擊空格：不允許，除非技能明確支援。

這套規則可以讓玩家透過站位、角色選擇和技能組合改變局勢。

### 羈絆標記的規則

1. 每個角色都有一個羈絆標記。
2. 當角色佔領棋格時，可以消耗標記，在相鄰的空格放置羈絆符號。
3. 羈絆符號不是角色，不能直接構成三子連線。
4. 角色站在羈絆符號旁邊時，可以觸發被動效果。
5. 符號可被敵人破壞，避免玩家無限建立安全區。

### 羈絆效果範例

| 羈絆   | 觸發條件      | 效果                |
| ---- | --------- | ----------------- |
| 守護羈絆 | 相鄰己方角色    | 首次受到傷害時減少 1 點     |
| 共鳴羈絆 | 兩名同陣營角色相鄰 | 攻擊力 +1，持續一回合      |
| 先鋒羈絆 | 首次佔領棋盤中心  | 獲得一次額外佔位行動        |
| 追擊羈絆 | 擊敗敵人後     | 下一次攻擊傷害 +1        |
| 連線羈絆 | 己方已有兩格連線  | 下一次攻擊可以無視 1 格距離限制 |

為避免開局過強，先鋒羈絆的額外行動應設定為每局一次，且不能再觸發其他額外行動。

### 核心程式邏輯

以下為不依賴特定引擎的核心規則示意，可作為 Godot 或 Unity 實作時的基礎。

```
public enum ActionType
{
    Place,
    Attack,
    UseSkill
}

public class CharacterData
{
    public string Id;
    public int MaxHp;
    public int Hp;
    public int Attack;
    public int Range;
    public bool IsAlive = true;
}

public class BoardCell
{
    public int X;
    public int Y;
    public string OccupantId;
    public bool IsSealed;

    public bool IsEmpty =>
        string.IsNullOrEmpty(OccupantId) && !IsSealed;
}

public class TurnState
{
    public int CurrentPlayer;
    public bool ActionUsed;
    public int ExtraPlacements;
}

// 每次普通行動只能執行一次。
// 佔位後角色不能自行離開棋格。
// 角色被擊敗時才清空其棋格。
//
// 特殊技能必須明確定義：
// 1. 是否消耗主要行動
// 2. 每局使用次數
// 3. 是否可觸發額外行動
// 4. 是否能影響已佔領棋格
// 5. 是否允許改變位置

```

### 必須先定義的技術細節

1. 佔位和攻擊如何選擇？ 建議點擊角色後，再點選空格或敵人。
2. 被攻擊時能否反擊？ 第一版建議不自動反擊，避免回合規則過於複雜。
3. 佔位後能否攻擊？ 可以，但需要消耗後續回合的行動。
4. 先手技能如何運作？ 只允許額外佔位，不能無限連鎖。
5. 棋格被封鎖時如何處理？ 不能佔位、不能計入連線；持續時間結束後恢復。
6. 棋盤上沒有可行動的角色時怎麼辦？ 若仍有可用技能則可以使用；否則跳過回合或結束對局，依遊戲狀態判斷。

## 10. 最終建議

《羈絆棋戰》的關鍵不只是三子連線，而是讓每個棋格同時具有連線價值、戰鬥風險與羈絆價值。

第一個可玩版本應聚焦於：

- 3×3 棋盤。
- 5 對 5 角色貼紙。
- 佔位後不可逃跑。
- 一回合一次行動。
- 近戰、遠程及簡單技能。
- 三子連線與全員擊敗。
- 羈絆先佔位符作為核心特色。

等這套規則玩起來有策略深度後，再加入角色收藏、更多技能、陣營克制和關卡挑戰，會比一開始就製作大量角色和特效更有效率。
