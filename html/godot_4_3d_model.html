1. 骨骼加載與末端骨骼 (Leaf Bones)

在 Blender 中導出角色前，務必為手部、腳部與頭部添加 **Leaf Bones**（末端小骨骼）。否則 Godot 自動對齊骨骼時會忽略未連接末端，導致 Ragdoll 布娃娃物理無法正常彎曲折疊。

2. 循環動畫命名規範

Blender Action Editor 中動畫命名後綴加上 _loop（如 idle_loop, run_loop）。Godot 導出 glTF 時會自動激活 Loop 循環屬性。

3. 貼圖渲染優化（Nearest）

低解析度像素風格（32x32）在 Godot 中，需將 Material 材底的 Sampling Filter 改為 **Nearest**（最近鄰居），防止像素邊緣產生模糊糊的線性插值。

4. 性能腳本點評

使用 velocity.length_squared() > 0.1 取代標準開根號長度計算，可避免每幀執行平方根，大幅提升大批次怪物的運算效能。
