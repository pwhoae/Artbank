根据 13 分钟拆解视频，闪卡的重叠反光由以下 4 个核心 CSS 图层配合 blend-mode 与 filter 组合而成：

图层 A: 基础多彩渐变 (Shine Layer) mix-blend: color-dodge

由大面积彩虹渐变(A1)、明暗明度条纹(A2)与跟随指针的径向渐变(A4)叠加而成，随 --background-x/y 位移。

图层 B: 动态斜向高亮条纹 (Foil Stripes) ::after pseudo / blend: hue

128° 斜向明暗条纹(B2)被彩虹色(B1)通过 background-blend-mode: hue 染色，营造真实卡片斜向反射。

图层 D: 外部聚光灯高光 (Glare Layer) mix-blend: hard-light

模拟外部自然光源打在卡片上的聚焦白光斑，圆心坐标实时与 --pointer-x/y 挂钩。

图层 F: 卡片细微金属磨砂纹理 (Foil Grain) blend-mode: difference

细密的不规则磨砂图片/点阵，固定不随指针滑动，产生“光在纹理深处流动”的真实质感。
