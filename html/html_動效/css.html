CSS & JS 核心代码实现解析

选择下方特效模块，直接预览并一键复制源码。

border-gradient.css 
/* CSS 自定义属性 @property 实现渐变边框旋转 */
@property --border-angle {
  syntax: '';
  initial-value: 0deg;
  inherits: false;
}

.gradient-rotate-border {
  background: linear-gradient(#1e293b, #0f172a) padding-box,
              conic-gradient(from var(--border-angle), #ff007f, #7928ca, #00dfd8, #ff007f) border-box;
  border: 3px solid transparent;
  animation: spinBorder 4s linear infinite;
}

@keyframes spinBorder {
  0% { --border-angle: 0deg; }
  100% { --border-angle: 360deg; }
}
