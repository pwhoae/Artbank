1. 現代 CSS 特效即時實驗室

親自調整參數，理解現代 CSS 屬性如何創建高品質視覺與視覺深度。

毛玻璃質感 (Glassmorphism)

backdrop-filter

將元素背景設為半透明，搭配 backdrop-filter: blur() 進行模糊化。疊加微弱的 Border 與 Shadow 可大幅增強逼真感。

Glassmorphism Card

即時響應式模糊與磨砂質感

3D 視差傾斜卡片 (Parallax Tilt)

transform-style: preserve-3d

根據滑鼠游標相對位置計算 rotateX 與 rotateY，讓內容透過 translateZ 浮出卡片，實現強烈空間深度感。

Zhangjiajie China

張家界 · 3D 視差

移動滑鼠探索多層次懸浮質感

TRAVELO VISION Hover Me

提示：將滑鼠於卡片上方移動即可感受 3D 傾斜與多層次浮動

@property 漸變旋轉邊框

CSS Houdini

透過 CSS 原生註冊自訂屬性 @property --gradient-angle，使得平時無法動畫化的漸變角度（conic-gradient）實現極致流暢的邊框旋轉。

Interactive Border

全新 border-box 漸變算法

不需要複雜的 DOM 結構，僅憑 CSS 自訂變數與 @property 即可製作媲美高階動畫的霓虹光暈旋轉邊框。

OKLCH 色彩與字重張力

oklch() & font-weight

OKLCH 提供更客觀的人眼感知一致性。配合粗細字重的心理暗示（粗字重代表力量與權威；細字重展現精緻與留白奢華感）。
