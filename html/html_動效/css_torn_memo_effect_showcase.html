CSS 撕纸动作与撕边核心实现原理

1 撕掉动画与分离 (Split)

通过将便签动态复制为上下两个重叠节点，给上节点应用 tear-piece-top，下节点应用 tear-piece-bottom，下节点叠加 @keyframes 离场下落。

2 `clip-path: polygon()` 裁切

在元素边缘利用多边形坐标，微调锯齿点的百分比（如 97% 100%, 94% 90%），实现模拟纤维破损的锯齿形状。

3 `drop-shadow()` 贴边阴影

将 filter: drop-shadow() 作用于撕纸的外层容器 Wrapper，让阴影完美跟随 Clip-path 裁切后的撕裂轮廓投射。

4 Web Audio 纸音效 & 颗粒

使用 Web Audio API 的 AudioContext 产生粉红噪点并做带通滤波处理，零依赖合成逼真的撕扯碎裂音效，并配合飞飞碎屑 Particles。
