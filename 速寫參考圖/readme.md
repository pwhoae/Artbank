
### 第一排（從左至右）

* **款式 1**：長袖飾，上方有荷葉邊飾，正面有兩個蝴蝶結，下襬為大片的雙層荷葉裙擺設計。
* **款式 2**：長袖飾，帶有縱向邊飾，側面有兩個蝴蝶結，下襬呈現開衩式荷葉邊。
* **款式 3**：長袖飾，整體較寬鬆，中段及袖口帶有豐富的波浪荷葉邊，袖口處有蝴蝶結繫帶。
* **款式 4**：長袖飾，設計簡潔，袖口處有兩層對稱的細摺邊與扣環細節。
* **款式 5**：長袖飾，上方為泡泡袖結構，腰身處有束帶，下方為擴散狀裙擺。

### 第二排（從左至右）

* **款式 6**：短袖飾，類似袖口設計，帶有尖角翻領與底層荷葉邊。
* **款式 7**：短袖飾，帶有簡單的直角袖口翻摺與下方荷葉邊。
* **款式 8**：短袖飾，環繞式設計，中心裝飾一個小蝴蝶結。
* **款式 9**：短袖飾，為蓬鬆的燈籠袖結構，底部收口處帶有荷葉邊。
* **款式 10**：短袖飾，帶有扣環束帶與細緻的邊緣褶皺。

### 第三排（從左至右）

* **款式 11**：長袖飾，上方有一個大蝴蝶結，下襬為寬鬆的荷葉喇叭袖。
* **款式 12**：長袖飾，修身款，頂部有帶扣環的頸部或肩部固定帶，下襬處有細密摺邊。
* **款式 13**：長袖飾，具備正式感的袖口翻摺與多層次裝飾結構。
* **款式 14**：長袖飾，背部帶有綁帶（Corset style）設計，下襬為層疊的荷葉邊。
* **款式 15**：長袖飾，同樣帶有背部綁帶設計，下襬為繁複且寬大的層疊波浪裙擺。
